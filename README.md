2. 產品特色

## 策略：
### 前端：
- 首頁

  - 超連結導向產品特色
- 產品特色
  - 公司專業與產品品項描述
  - 超連結導向產品頁面
- 產品
  - 每個產品必須有標題與圖片
  - 點擊標題與圖片會到內頁，會有產品細節說明
- 最新消息
  - 最近公司異動
- 常見問題
  - Q / A
- 目錄下載(型錄/技術文件)
  - PDF檔案下載頁面
- 諮詢表單管理
  - 會有一個表單，用來新增諮詢產品細節

### 後端：
- 首頁管理

  - 公司專業與產品品項描述 CRUD

  - 產品分類CRUD

  - 上傳 / 刪除PDF
- 諮詢表單管理
  - 顯示表單修改與查詢
 
## 規格：
### 前端：
- 樣板：
  - 首頁圖片橫幅
  - 導覽列
  - 下方 公司資訊
- 首頁：
  - 有個相簿功能，一段時間會換頁，隨機選擇5個
  - 下面以三個圖片與標題為一行，
  - 大部分是員工與工廠的圖片，
  - 隨機顯示順序，最多8行
  - 公司歷史說明
- 產品特色
  - 公司專業與產品品項描述
- 產品介紹：
  - 左邊出現產品分類
  - 顯示預設產品，預設顯示每行5個，最多8行
  - 點選圖片與標題，會到產品內頁，內頁裡產品規格
- 產品
  - 每個產品必須有標題與圖片
  - 點擊標題與圖片會到內頁，會有產品細節說明
  - 超連結導向目錄下載頁面
- 最新消息
  - 最近公司異動
- 常見問題
  - Q / A 說明
- 目錄下載(型錄/技術文件)
  - PDF檔案下載頁面
- 諮詢表單管理
  - 會有一個表單，用來新增諮詢產品細節
- 公司名稱
  - *聯絡人名稱
  - 地址
  - *聯絡人市話 / 手機
  - *Email
  - *詢問主題
  - *內容

### 後端：
- 樣板：
  - 左邊導覽列，列出各個操作的頁面
  - 個別導覽列在上方
- 首頁管理
  - 橫幅相簿 CRUD
    - 旁邊會有修改與刪除功能
  - 員工與工廠圖片CRUD
    - 旁邊會有修改與刪除功能
  - 公司沿革文章CRUD
    - 修改文章
- 產品特色管理
  - 公司專業與產品品項描述 CRUD
    - 修改公司專業文章
    - 修改產品品項文章
- 產品管理
  - 產品分類CRUD
    - 旁邊會有修改與刪除功能
    - 修改可以直接改分類名稱
  - 各類產品CRUD
    - 旁邊會有刪除功能
- 最新消息管理
  - 新聞內容 CRUD
- 常見問題管理
